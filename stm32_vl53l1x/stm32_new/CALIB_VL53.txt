          HƯỚNG DẪN HIỆU CHUẨN (CALIBRATION) CẢM BIẾN LASER ToF VL53L1X
                     DỰ ÁN: STM32F4 <-> PLC MITSUBISHI Q-SERIES

1. BẢNG TRA CỨU MÃ LỆNH HIỆU CHUẨN QUA PLC (D910 & D911):
--------------------------------------------------------------------------------
Hệ thống cho phép thực hiện hiệu chuẩn từ xa trực tiếp từ PLC/HMI thông qua 2 ô nhớ:
  - D910: Cự ly khoảng cách chuẩn đặt từ PLC (Đơn vị: mm).
  - D911: Mã lệnh kích hoạt chế độ hiệu chuẩn (10, 20, 30).

+-------+-------------------------+--------------------------------------------+
| D911  | CHẾ ĐỘ HIỆU CHUẨN       | NGUYÊN LÝ & CÁCH SỬ DỤNG                   |
+-------+-------------------------+--------------------------------------------+
|   0   | RUN MODE (Mặc định)     | Chế độ vận hành bình thường. Màn hình OLED |
|       |                         | hiển thị số đo khoảng cách Font Siêu Lớn.  |
+-------+-------------------------+--------------------------------------------+
|  10   | Calib Offset Phần Mềm   | Tính Offset = D910 - D_Raw và lưu Flash    |
| (hoặc | (SW OFFSET)             | STM32 Sector 5. Dễ dùng nhất trên HMI/PLC. |
|   1)  |                         |                                            |
+-------+-------------------------+--------------------------------------------+
|  20   | Calib Offset Phần Cứng  | Gọi ST API VL53L1X_CalibrateOffset() nạp   |
|       | (HW OFFSET)             | trực tiếp vào thanh ghi nội cảm biến.      |
|       |                         | (Mặc định cự ly chuẩn ST là 140 mm).       |
+-------+-------------------------+--------------------------------------------+
|  30   | Calib Crosstalk         | Gọi ST API VL53L1X_CalibrateXtalk() triệt  |
|       | (XTALK GLASS)           | tiêu phản xạ khi lắp sau nắp kính / mica.  |
|       |                         | (Mặc định cự ly chuẩn ST là 500 mm).       |
+-------+-------------------------+--------------------------------------------+
| Khác  | Hướng dẫn nhập lệnh     | Màn hình OLED tự hiện bảng [CALIB GUIDE]   |
|       | (CALIB GUIDE / HELP)    | hướng dẫn người dùng nhập đúng 10, 20, 30. |
+-------+-------------------------+--------------------------------------------+

* LƯU Ý ĐẶC BIỆT:
  - Sau khi Calib hoàn tất (Mode 10, 20, 30), STM32 sẽ TỰ ĐỘNG GHI XÓA D911 = 0 
    ngược về lại PLC để báo hiệu hoàn tất và đưa màn hình trở lại RUN MODE.

2. QUY TRÌNH THỰC HIỆN HIỆU CHUẨN TỪNG CHẾ ĐỘ:
================================================================================

--- A. CHẾ ĐỘ 1: CALIB OFFSET PHẦN MỀM (D911 = 10 hoặc 1) ---
Ứng dụng: Bù trừ sai số cự ly gá đặt cơ khí (Nhanh và tiện nhất).
Bước 1: Đặt vật cản trước cảm biến ở khoảng cách mong muốn (Ví dụ: 300 mm).
Bước 2: Trên PLC/HMI, nhập D910 = 300.
Bước 3: Nhập D911 = 10.
Bước 4: STM32 tự tính Offset = 300 - D_Raw, lưu Flash, hiện "CALIB SUCCESS" 
        và tự động xóa D911 về 0.

--- B. CHẾ ĐỘ 2: CALIB OFFSET PHẦN CỨNG (D911 = 20) ---
Ứng dụng: Hiệu chuẩn chuẩn của hãng ST.
Bước 1: Đặt tấm bia màu trắng (độ phản xạ 88% hoặc 17%) cách cảm biến 140 mm.
Bước 2: Nhập D910 = 140 (hoặc để trống nếu dùng 140 mặc định).
Bước 3: Nhập D911 = 20.
Bước 4: Cảm biến tự đo 50 lần, ghi hệ số bù vào thanh ghi nội (0x001E), lưu Flash 
        và tự động xóa D911 về 0.

--- C. CHẾ ĐỘ 3: CALIB CROSSTALK (D911 = 30) ---
Ứng dụng: Triệt tiêu phản xạ khi cảm biến được đặt sau tấm kính hoặc Mica bảo vệ.
Bước 1: Lắp cố định nắp kính/mica bảo vệ phía trước cảm biến.
Bước 2: Đặt tấm bia cách mặt kính đúng 500 mm.
Bước 3: Nhập D910 = 500 (hoặc để trống nếu dùng 500 mặc định).
Bước 4: Nhập D911 = 30.
Bước 5: Cảm biến tự đo và lưu hệ số triệt quang vào thanh ghi nội, lưu Flash 
        và tự động xóa D911 về 0.

3. BẢNG ÁNH XẠ Ô NHỚ TRUYỀN THÔNG (MC PROTOCOL FORMAT 5):
================================================================================

[GỬI TỪ STM32 LÊN PLC] (Batch Write 6 Words: D900..D905)
  - D900: Khoảng cách sau lọc và hiệu chuẩn (mm) - Font siêu lớn trên OLED.
  - D901: Khoảng cách đo thô chưa bù (mm).
  - D902: Trạng thái hệ thống (Bit 0: Sensor OK, Bit 1: Near, Bit 2: In-range, Bit 3: Calib OK).
  - D903: Mã lỗi cảm biến (0: OK, 10: Boot err, 20: Init err, 30: I2C err).
  - D904: Chu kỳ quét lấy mẫu (ms).
  - D905: Heartbeat (Tự tăng liên tục mỗi chu kỳ truyền).

[ĐỌC TỪ PLC XUỐNG STM32] (Batch Read 2 Words: D910..D911)
  - D910: Cự ly chuẩn đặt từ PLC / HMI (mm).
  - D911: Cờ lệnh điều khiển hiệu chuẩn (0: Run, 10: SW Offset, 20: HW Offset, 30: Xtalk).
